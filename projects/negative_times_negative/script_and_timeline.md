# 《为什么负负得正？—— 数轴翻转的几何直觉》时间轴脚本

## 📽️ 视频概览卡

- **视频主题**：为什么 \((-a)\times(-b)=ab\)？负负得正不是人为规定，而是「翻转两次」的必然结果。
- **核心 Aha! 顿悟点**：数轴上「乘以 \(-1\)」= 让箭头绕原点**原地转身 180°**。负号 = 一次方向反转，两个负号 = 反转两次 = 回到原方向 → 负负得正。
- **美学主题**：`claude_light`（象牙米纸底 + 深墨文字 + 墨韵石板蓝 + 赤陶橙 + 暖金琥珀）
- **镜头语言**：数轴由上而下展开 → 箭头伸缩 → 绕原点旋转 180° → 位移复合 → 公式演化 → 结论定格
- **预估总时长**：约 2 分 40 秒（4 幕模块化架构）

> **实现备注**：4 幕均已落地（`scene_01_scale.py` / `scene_02_flip.py` / `scene_03_displacement.py` / `scene_04_general.py`），
> 已通过静态检查与四幕关键帧排版质检。Scene 3 的口播在生产时拆成了 4 句以便与动画逐步对齐。
- **颜色语义**：正方向 / 正数 = 墨韵石板蓝；负方向 / 负号 = 赤陶橙；翻转扫过的圆弧 = 暖金琥珀；结论 = 暖金琥珀

## ✍️ 创作备注

1. **统一装置**：全片共用同一条数轴（`AXIS_Y`、刻度长度、字号）与同一套箭头构造，保证 4 幕视觉严格一致；公共部分全部放 `project_style.py`。
2. **声画同步**：每句台词用 `speech(self, caption=..., spoken=...)` 包裹；字幕允许出现 `(-1)×(-1)=1` 之类的符号，口播一律写「负一乘负一等于正一」，避免 TTS 念错。
3. **翻转动效**：Scene 2 / 3 / 4 都用「绕原点旋转 180°」的同一种动效语言，让「负号 = 转身」成为反复强化的视觉母题。
4. **可换肤**：把 4 幕的 `DEFAULT_THEME` 改成 `3b1b_dark` / `chalkboard` / `nord` 即一键换风格。
