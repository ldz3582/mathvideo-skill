## 视频概览卡

- **核心 Aha!**：圆被切成 n 个扇形交错重排后，底边 = 半个圆周 = πr、高 = r；
  份数 → ∞ 时波浪边被拉直，平行四边形塌缩成矩形，面积从没变过，于是 S = πr·r = πr²。
- **镜头语言**：静机位为主，靠图形自身运动（切分 → 飞舞重排 → 加密 → 定型）叙事。
- **分幕数**：5 幕。
